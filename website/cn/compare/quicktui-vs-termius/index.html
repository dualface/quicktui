QuickTUI 对比 Termius

QuickTUI 与 Termius 都能帮你在手机上处理终端或 AI Agent 的工作，但出发点不同。本页说明两者的区别。

Termius 是什么

Termius 是一款成熟的跨平台 SSH 客户端，支持 SSH、Mosh、Telnet、SFTP 和串口，主机和密钥可以通过云端保险库在设备之间同步。它近来加入了面向 AI Agent 的便利功能，例如连接时自动启动 Agent、带语音输入的输入框，以及把图片上传到主机后粘贴路径。

QuickTUI 是什么

QuickTUI 是原生 iPhone、iPad 与 Android（Preview）App，搭配装在你电脑上的 QuickTUI 服务端，让你在手机上直接接入电脑里正在运行的会话，运行和照看任何 CLI Agent。它的优势在于：

真正的终端，接入已有会话
直接接入电脑上的 tmux 与 Herdr 会话，不需要用包装器改变 Agent 的启动方式，电脑前和手机上是同一个会话。
Agent 状态一目了然
使用 Herdr 时，会话管理器显示每个 Agent 是空闲、工作中、等待输入还是已完成。
安装配对一步到位
设置向导通过 SSH 一次性装好服务端并自动配对，之后不需要在手机上管理 SSH。
端到端加密，默认直连
手机与电脑之间全程端到端加密；不在同一网络时，可经 VPN、隧道或可选的 QuickTUI Relay 连接，无需开放 SSH。
为手机操作而设计
Agent 向导内置 19 种常用 Agent 的启动配置，命令面板收录 500 多条常用命令，另有可堆叠的快捷栏、支持文件与图片附件的输入栏、文件管理器，以及端口转发与内置浏览器。
一次性买断
iPhone 与 iPad 上，免费版可连接一台电脑，Pro 一次性买断（中国区 App Store 为 168 元），不限电脑数量，中国区 App Store 同样可以下载；Android（Preview）在预览期间免费提供全部功能。

逐项对比

界面
QuickTUI：完整终端与聊天视图，加上会话管理器、Agent 向导、文件管理器和端口转发Termius：通用 SSH 终端，带输入框、代码片段和快捷栏
连接方式
QuickTUI：App 连接你电脑上的 QuickTUI 服务端，可在局域网直连，也可经 VPN、隧道或可选的 QuickTUI Relay；设置向导通过 SSH 一次性安装服务端Termius：从手机直接 SSH 或 Mosh 到你的服务器
数据是否经过厂商云端
QuickTUI：默认直连你的电脑；使用 Relay 时只转发端到端加密的数据Termius：终端流量不经过 Termius；保险库同步经过 Termius 云端（官方称端到端加密）
tmux / Herdr
QuickTUI：原生支持 tmux 与 Herdr，也可手动启用 Luvus；使用 Herdr 时显示每个 Agent 的状态Termius：没有原生 tmux 集成，官方建议在 tmux 中运行 Agent 并设置启动时 attach
支持的 Agent
QuickTUI：任何终端里的 CLI Agent；Agent 向导内置 19 种常用 Agent 的启动配置Termius：任何 CLI Agent，可以设置连接时自动启动
平台
QuickTUI：iPhone、iPad 与 Android（Preview）Termius：iOS、iPadOS、Android、macOS、Windows、Linux
定价
QuickTUI：免费版可连接一台电脑；Pro 一次性买断（中国区 App Store 为 168 元），不限电脑数量；Relay 为可选订阅；Android（Preview）预览期间免费Termius：入门版免费；Pro 按年付费每月约 10 美元，另有团队与企业版
中国区 App Store
QuickTUI：有Termius：有

QuickTUI 可以从 App Store 免费下载，安装方法见安装指南。

Termius 的信息根据其官网与 App Store 页面整理，截至 2026 年 9 月，最新情况请以对方官网为准。
