在手机上掌控 AI Agent

想用手机控制编程 Agent，做法是让 Agent 运行在你电脑的终端里，再从手机接入这个终端。QuickTUI 支持 Claude Code、Codex、Grok Build、OpenCode、Pi、Kimi Code 以及其他任何 CLI Agent：在 iPhone、iPad 或 Android（Preview）上启动、查看、批准和引导每一次运行，放下手机后 Agent 仍在电脑上继续工作。

在手机上掌控 Agent 意味着什么

启动任务
用 Agent 向导启动 Agent，或在终端中输入它的命令，然后交给它一个任务。
查看真实终端
你看到的是 Agent 的实时终端输出和回滚历史，而不是摘要。
批准与引导
回答 Agent 的提问，批准或拒绝工具调用，在它跑偏时及时纠正，和坐在电脑前一样。
持续运行
Agent 运行在电脑上的 tmux 或 Herdr 中，关闭 App 后仍会继续工作。网络切换或短暂断线后，App 会重新接入同一个会话。

支持的 Agent

任何在终端里运行的 Agent 都可以通过 QuickTUI 使用。下面这些 Agent 在 App 中有专门支持：

Claude Codetmux、Herdr支持支持Claude Code 指南
Codextmux、Herdr支持支持Codex 指南
Grok Buildtmux、Herdr支持支持Grok Build 指南

Agent 向导还可以启动 Cursor、Qoder、Gemini、GitHub Copilot、Qwen Code、Kiro、Factory Droid、Mistral Vibe、Crush、Amp、Goose 和 Auggie，其中 Mistral Vibe、Crush、Goose 和 Auggie 只能在 tmux 中启动。其他 CLI Agent 同样可用，在终端中输入它的命令即可。

用 Agent 向导启动 Agent

Agent 向导让你不输入命令也能启动 Agent。它会在当前 tmux 会话中新建一个窗口，或在当前 Herdr 工作区中新建一个标签页来运行 Agent。Luvus 后端不支持 Agent 向导。

模式
各 Agent 自带的权限模式，例如默认模式、计划模式或 YOLO 模式（执行工具前不再询问）。
模型与推理强度
选择模型；支持推理强度的 Agent 还可以设置推理强度。
工作目录
选择 Agent 启动时所在的目录，最近使用的目录可以直接选。
恢复会话
继续之前的 Agent 会话。tmux 支持恢复，Herdr 不支持。
预设与自定义模型
把常用设置保存为预设，也可以在 设置 → Agent 模型中添加自己的模型。

如果电脑上没有安装对应的 Agent，App 会提示找不到它的命令。先安装 Agent，再重新启动即可。

同时照看多个 Agent

给每个 Agent 一个独立的窗口或标签页：一个开发新功能，一个跑测试，一个审查 Pull Request。配合 Herdr，会话管理器会显示每个 Agent 处于空闲、工作中、等待输入还是已完成，需要你处理的一眼就能看到。Claude Code、Codex、OpenCode 和 Grok 在列表中还有各自的图标。

iPhone 与 iPad 上，免费版可连接一台电脑，QuickTUI Pro 一次性买断，不限电脑数量。Android 应用（Preview）在预览期间免费提供全部功能。

如何开始

  1. 从 App Store 安装 QuickTUI，或安装 Android 应用（Preview），然后打开设置向导。
  2. 选择 通过 SSH 连接并启用增强功能（推荐），填写运行 Agent 的 Mac 或 Linux 电脑的 SSH 登录信息。
  3. 点 安装。App 会通过 SSH 安装 QuickTUI 服务端并自动完成配对；电脑上没有 tmux 和 Herdr 时，会自动安装 Herdr。

不支持 SSH 登录的 Mac 或 Linux 电脑，先在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

Windows 电脑请从 Microsoft Store 获取 QuickTUI Server，从开始菜单打开后扫描它显示的二维码。Windows 上的会话运行在 Herdr 中，Herdr 需另行安装，见安装指南的 Windows 一节。

手机与电脑之间的连接端到端加密，默认直连你的电脑。详见安装指南。

常见问题

可以用手机控制 Claude Code 或 Codex 吗？

可以。让 Agent 运行在电脑上的 tmux 或 Herdr 中，再用手机上的 QuickTUI 打开这个会话。你看到的是实时终端，可以下达指令、批准工具调用、查看改动。详见 Claude Code 与 Codex 指南。

QuickTUI 支持哪些 AI Agent？

任何在终端中运行的 CLI Agent 都可以使用。Agent 向导内置 19 种 Agent 的启动设置，包括 Claude Code、Codex、Grok Build、OpenCode、Pi、Kimi Code、Gemini、GitHub Copilot 和 Cursor。

关闭 App 后 Agent 还会继续运行吗？

会。Agent 运行在电脑上的 tmux 或 Herdr 会话中，而不是在手机上。重新打开 App，就回到同一个实时会话。

可以同时运行多个 Agent 吗？

可以。每个 Agent 放在独立的窗口或标签页中，在 App 里随时切换。配合 Herdr，会话管理器会显示每个 Agent 的状态。

我的代码会经过 QuickTUI 的服务器吗？

不会。App 默认直连你的电脑，连接端到端加密。只有无法直连时才会用到可选的 Relay，它转发的是无法解读的加密数据。
