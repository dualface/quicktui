Run the Pi coding agent from your phone

To run the Pi coding agent from your phone, keep Pi on your computer and connect to it with QuickTUI. You drive the real Pi terminal UI from iPhone, iPad or Android, and Pi keeps working on your computer between check-ins.

What is Pi?

Pi is a minimal, extensible coding agent for the terminal. It was created by Mario Zechner and is now maintained by Earendil under the MIT license (earendil-works/pi, formerly badlogic/pi-mono). Pi works with many model providers and keeps its core small; features such as sub-agents and plan mode come from extensions.

Set up Pi and QuickTUI

  1. Install Pi on the computer where it should run: 
    # macOS / Linux
curl -fsSL https://pi.dev/install.sh | sh

# Windows
powershell -c "irm https://pi.dev/install.ps1 | iex"

# or with npm (Node.js 22.19 or later)
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
  2. Run pi and sign in with /login, or set your provider's API key as an environment variable.
  3. Install QuickTUI on your phone: from the App Store for iPhone and iPad, or the Android (Preview) build.
  4. In the app's setup wizard, choose Connect Over SSH — Enable Enhanced Features (Recommended), enter the computer's SSH login and tap Install. The app installs the QuickTUI server and pairs automatically. If the computer has neither tmux nor Herdr, it installs Herdr.

On a Mac or Linux computer without SSH access, run the install command on the computer, then pair by scanning a QR code:

curl -fsSL https://quicktui.ai/q.sh | sh

On Windows, get QuickTUI Server from Microsoft Store, open it from the Start menu and scan the QR code it shows. Sessions on Windows run in Herdr, which you install separately; see Windows in the install guide.

The connection between your phone and your computer is end-to-end encrypted and direct by default. See the install guide for details.

Start Pi from your phone

Open the Agent Wizard in the app, choose Pi, and QuickTUI starts it in a new window of the current tmux session or a new tab of the current Herdr workspace. The wizard isn't available on the Luvus backend.

Mode
Pi runs in its default mode; the wizard has no YOLO option for Pi.
Model
deepseek-flash is preset, passed with --model. Add your own under Settings > Agent Models.
Thinking level
Passed with --thinking.
Resume
Continue an earlier session with --session. Resume isn't available when the workspace runs on Herdr.
Working directory
Pick the project folder, with recently used folders one tap away. Save frequent combinations as presets.

You can also start it yourself on the computer, in a named tmux session you can find later in the app:

tmux new-session -s pi
pi

Tips for Pi on a phone

Shift+Enter in tmux
Pi uses Shift+Enter for a new line. In tmux, turn on extended keys or it behaves like Enter. For tmux 3.5 and later: 
set -g extended-keys on
set -g extended-keys-format csi-u
For tmux 3.2 to 3.4, add only set -g extended-keys on.
Regular or full-screen UI
Pi's regular mode writes to normal terminal scrollback; full-screen mode takes over the screen. Switch with --tui-mode or in /settings. In tmux, full-screen mode keeps repeated output out of tmux scrollback; see the FAQ.
Send screenshots
Attach a file, image or camera photo from the Input Bar. It's uploaded to your computer (up to 10 MiB) and its path is inserted, so Pi can read it.
Common commands in one tap
The command palette includes a Pi group with its frequently used commands, so you don't have to type them on a phone keyboard.
See which session needs you
With Herdr, the Session Manager shows whether each Pi session is idle, working, waiting for input or done.

Running Pi on the phone vs on your computer

Pi's documentation also explains how to install Pi on an Android phone through Termux, so the agent runs on the phone itself. QuickTUI does the opposite: Pi stays on your computer, next to your repositories, tools and credentials, and keeps running while the phone is locked or offline. The phone is only the screen and keyboard.

FAQ

Can I use the Pi coding agent on my phone?

Yes. Run Pi on your computer and connect with QuickTUI from an iPhone, iPad or Android phone to give it tasks, answer its questions and review its work.

Does Pi keep running when I close the app?

Yes. It runs in a tmux or Herdr session on your computer and keeps going after you close the app. Reopen the app to return to the live session.

Why does Shift+Enter send my message in tmux?

tmux doesn't pass Shift+Enter through unless extended keys are enabled. Add the tmux settings above, reload tmux, and Shift+Enter inserts a new line again.

Does my code go through QuickTUI's servers?

No. By default the app connects directly to your computer, end-to-end encrypted. Pi itself talks to the model provider you configured.
