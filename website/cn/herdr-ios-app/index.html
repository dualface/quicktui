Herdr · iOS

iPhone 和 iPad 上的 Herdr：在手机上操作电脑里的 Agent

Herdr 是为 AI 编程 Agent 设计的终端工作区管理器，让每个 Agent 在自己的终端里持续运行。QuickTUI 让你在 iPhone 和 iPad 上打开这些工作区，随时查看每个 Agent 的状态并接手操作。

Herdr 是什么

Herdr 是一个开源（Apache 2.0）的终端工作区管理器，以单个 Rust 程序的形式在后台运行，终端都运行在它里面。它支持 macOS、Linux 和 Windows。

和 tmux 一样，Herdr 会在你断开后让终端继续运行；不同的是，它能识别哪些终端里运行着 Agent，并判断每个 Agent 是在工作、等待输入还是已经空闲。

为什么推荐在 QuickTUI 中使用 Herdr

Agent 状态一目了然
会话管理器中的每个标签页和窗格都显示 Agent 状态：空闲、工作中、等待输入或已完成。离开电脑时，也能在手机上看到哪个 Agent 需要你处理。
Agent 向导直接启动
在 App 中用 Agent 向导选择 Agent、模型和参数，QuickTUI 会在 Herdr 中新建标签页并启动它。ZCode、Mistral Vibe、Crush、Goose 和 Auggie 不能以这种方式在 Herdr 中启动，可以改用 tmux，或在 Herdr 标签页中直接输入命令。
默认后端
Herdr 可用时，服务端默认使用 Herdr；电脑上没有 tmux 和 Herdr 时，安装器会自动安装 Herdr。
Windows 也能用
Windows 上的会话都运行在 Herdr 中，QuickTUI 在 Windows 上只支持 Herdr。
断线后接着用
短暂断线后重新连接时，会继续使用原来的终端画面。保留时长由配置项 herdr_client_retention 控制，默认 5 分钟。

如何开始

  1. 从 App Store 安装 QuickTUI，打开设置向导。
  2. 选择 通过 SSH 连接并启用增强功能（推荐），填写电脑的 SSH 登录信息。
  3. 点 安装。电脑上还没有 tmux 或 Herdr 时，安装器会自动安装 Herdr，并完成配对。

不支持 SSH 登录的 Mac 或 Linux 电脑，在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

Windows 电脑请从 Microsoft Store 获取 QuickTUI Server，从开始菜单打开后扫描它显示的二维码。Windows 上的会话运行在 Herdr 中，Herdr 需另行安装，见安装指南的 Windows 一节。

已经装有 tmux、想改用 Herdr 时，先安装 Herdr，再重启 QuickTUI 服务：

# macOS / Linux
curl -fsSL https://herdr.dev/install.sh | sh
~/.local/bin/quicktui-server service restart

服务端会自动检测并启用 Herdr，也会在需要时自动启动它，无需手动运行。QuickTUI 需要 Herdr v0.8.0 及以上版本，复制模式需要 v0.9.0 及以上。更多安装方式见 FAQ。

Herdr 在 App 中的对应关系

Herdr 工作区
在 App 中显示为 工作区，顺序与 Herdr 侧边栏一致。
Herdr 标签页
在 App 中显示为 会话，并带有 Agent 状态图标。
Herdr 窗格
在 App 中仍是窗格，可以切换、放大和关闭。

在手机上能做什么

工作区
新建和重命名工作区。关闭工作区需要在电脑上的 Herdr 中操作。
会话（标签页）
新建、重命名和关闭标签页。每个工作区至少保留一个标签页。
窗格
切换、放大和关闭窗格。拆分窗格和调整布局需要在电脑上操作。
滚动与复制
滚动浏览输出，复制模式下输出不会暂停（需要 Herdr v0.9.0 及以上）。

同时使用 tmux

tmux 与 Herdr 可以同时启用，App 会分别列出两个后端的工作区，新建时可以选择后端。关于 tmux 的支持，见 iPhone 和 iPad 上的 tmux。

常见问题

需要先手动启动 Herdr 吗？

不需要。QuickTUI 服务端会在需要时自动启动 Herdr。在 App 中断开连接也不会停止 Herdr 或关闭任何窗格。

iPad 上能用吗？

能。同一个 App 支持 iPhone 与 iPad。另有 Android 应用（Preview）。

收费吗？

Herdr 是开源软件。iPhone 与 iPad 上，QuickTUI 免费下载，免费版可以连接一台电脑；QuickTUI Pro 为一次性买断，解锁不限数量的电脑。Android 应用（Preview）在预览期间免费提供全部功能。QuickTUI Relay 是可选的订阅服务，只在无法直连时需要。
