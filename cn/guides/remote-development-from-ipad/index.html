从 iPad 远程开发（2026）

一旦工作跑在真正的服务器上、平板只负责承载终端，iPad 就成了一块称职的开发平面。本指南用 QuickTUI 配置从 iPad 远程开发：接入你的服务器终端、运行编程 Agent、让长任务保持存活，并在需要时退回浏览器客户端。

这套模式很直接：编译器、仓库和 Agent 全都活在你自己托管的机器上；iPad 通过你自己的服务器接上一个实时终端视图。平板上不跑重活，所以电量和发热都不来添乱，而这个会话就是你在办公桌上用的那一个。QuickTUI 正为此提供了原生 iPad 应用外加浏览器客户端。

配置服务端

在存放你代码的机器上安装 QuickTUI：一台工作站、家用服务器或云主机。它会配置好服务，必要时还能装上 tmux 3.2+。

macOS / Linux

curl -fsSL https://quicktui.ai/q.sh | sh

Windows (PowerShell)

irm https://quicktui.ai/q.ps1 | iex

扫描 quicktui-server --qrcode 完成 iPad 应用的配对，或者用 URL 和 token 添加服务器。连接默认直连，所以你的代码和密钥绝不经过我们的服务器。

在 iPad 上工作

  • 接入你的终端。打开服务器上的会话，你就进入了实时画面：tmux 的窗口、窗格和回滚缓冲，在 iPad 上和在桌面上别无二致。
  • 运行 Agent。在会话里启动 Claude Code、Codex 或任意 CLI，并从平板驱动它；无需离开终端就能监督、批准和引导。
  • 让长任务保持存活。构建、测试套件和 Agent 运行在你断开后仍留在 tmux 里继续跑。会话保活会跨越 Wi-Fi 切 LTE 或 5G、应用切后台和连接中断重新接回。
  • 浏览器兜底。当你不想用应用时，打开由你自己服务器提供的浏览器客户端，从 Safari 里接上同一个会话。
硬件键盘。配上妙控键盘或任意蓝牙键盘，iPad 就表现得像一台正经终端：方向键、修饰键和控制序列都会传递给 tmux 和 shell，所以按键绑定和复制模式都如常工作。

常见问题

我真的能这样在 iPad 上开发吗？

能。构建工具、仓库和 Agent 都跑在你的服务器上；iPad 接上一个实时终端视图。配上硬件键盘，它就像任何笔记本上的终端一样好用。

如果我关掉 iPad，长时间运行的任务还在吗？

在。任务跑在服务器的 tmux 里，在你断开后仍会继续。当你重新打开应用或浏览器客户端时，QuickTUI 的会话保活会重新接回实时会话。

有浏览器选项吗？

有。你的服务器托管了一个浏览器客户端，所以当你不想用应用时，可以从 Safari 或任意浏览器接上同一个会话。
