在手机上运行 Pi 编程 Agent

要在手机上使用 Pi 编程 Agent，做法是让 Pi 留在你自己的电脑上运行，再用 QuickTUI 连接。你在 iPhone、iPad 或 Android 上操作的是真实的 Pi 终端界面，两次查看之间 Pi 会在电脑上继续工作。

Pi 是什么

Pi 是一个精简、可扩展的终端编程 Agent，由 Mario Zechner 创建，现由 Earendil 维护，采用 MIT 协议（earendil-works/pi，原 badlogic/pi-mono）。Pi 支持众多模型服务商，核心保持精简，子 Agent、计划模式等功能通过扩展提供。

安装 Pi 与 QuickTUI

  1. 在要运行 Pi 的电脑上安装： 
    # macOS / Linux
curl -fsSL https://pi.dev/install.sh | sh

# Windows
powershell -c "irm https://pi.dev/install.ps1 | iex"

# 或使用 npm（需要 Node.js 22.19 及以上）
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
  2. 运行 pi，用 /login 登录，或把模型服务商的 API key 设置为环境变量。
  3. 在手机上安装 QuickTUI：iPhone 和 iPad 从 App Store 下载，Android 使用 Android 应用（Preview）。
  4. 在 App 的设置向导中选择 通过 SSH 连接并启用增强功能（推荐），填写电脑的 SSH 登录信息，点 安装。App 会安装 QuickTUI 服务端并自动完成配对；电脑上没有 tmux 和 Herdr 时，会自动安装 Herdr。

不支持 SSH 登录的 Mac 或 Linux 电脑，先在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

Windows 电脑请从 Microsoft Store 获取 QuickTUI Server，从开始菜单打开后扫描它显示的二维码。Windows 上的会话运行在 Herdr 中，Herdr 需另行安装，见安装指南的 Windows 一节。

手机与电脑之间的连接全程端到端加密，默认直连。详见安装指南。

从手机启动 Pi

在 App 中打开 Agent 向导，选择 Pi，QuickTUI 会在当前 tmux 会话中新建窗口，或在当前 Herdr 工作区中新建标签页来启动它。Luvus 后端不支持 Agent 向导。

模式
Pi 只有默认模式，向导中没有 YOLO 选项。
模型
预置 deepseek-flash，通过 --model 传入。也可以在「设置 > Agent 模型」中添加自定义模型。
思考强度
通过 --thinking 传入。
恢复会话
用 --session 继续之前的会话。工作区运行在 Herdr 上时不支持恢复。
工作目录
选择项目文件夹，最近用过的文件夹可以直接点选。常用组合可以保存为预设。

也可以在电脑上自己启动，放在一个有名字的 tmux 会话里，之后在 App 中就能找到：

tmux new-session -s pi
pi

在手机上使用 Pi 的建议

tmux 中的 Shift+Enter
Pi 用 Shift+Enter 换行。在 tmux 中需要开启扩展按键，否则 Shift+Enter 会被当作 Enter。tmux 3.5 及以上： 
set -g extended-keys on
set -g extended-keys-format csi-u
tmux 3.2 至 3.4 只需加入 set -g extended-keys on。
普通模式与全屏模式
Pi 的普通模式把输出写入终端的滚动历史，全屏模式则占用整个屏幕。可以用 --tui-mode 或在 /settings 中切换。在 tmux 中使用全屏模式，可以避免重复输出写进 tmux 回滚历史，详见 FAQ。
发送截图
在输入栏中附加文件、图片或相机照片。文件会上传到电脑（上限 10 MiB），并把路径填入输入内容，Pi 就能读取它。
常用命令一键发送
命令面板内置 Pi 分组，收录了常用命令，不必在手机键盘上逐字输入。
看清哪个会话需要你
使用 Herdr 时，会话管理器会显示每个 Pi 会话是空闲、工作中、等待输入还是已完成。

在手机上运行 Pi，还是在电脑上运行

Pi 的文档也介绍了如何通过 Termux 把 Pi 安装在 Android 手机上，让 Agent 直接在手机里运行。QuickTUI 的做法相反：Pi 留在电脑上，紧挨着你的代码仓库、工具和凭据，手机锁屏或断网时也照常运行，手机只负责显示和输入。

常见问题

可以在手机上使用 Pi 编程 Agent 吗？

可以。在电脑上运行 Pi，再用 iPhone、iPad 或 Android 手机上的 QuickTUI 连接，就能下达任务、回答它的提问、查看它的工作。

关闭 App 后，Pi 还会继续运行吗？

会。它运行在电脑上的 tmux 或 Herdr 会话中，关闭 App 后照常工作。重新打开 App 即可回到正在运行的会话。

为什么在 tmux 中按 Shift+Enter 会直接发送消息？

tmux 默认不会传递 Shift+Enter，需要开启扩展按键。加入上面的 tmux 设置并重新加载后，Shift+Enter 就会重新插入换行。

我的代码会经过 QuickTUI 的服务器吗？

不会。App 默认直连你的电脑，全程端到端加密。Pi 本身照常与你配置的模型服务商通信。
