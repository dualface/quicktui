从手机操控 AI 编程 Agent

AI 编程 Agent 在有人盯着时表现最佳：把它们启动起来、批准有风险的步骤、在它们跑偏时拉回正轨。QuickTUI 把这份掌控放进你的口袋：在你自己的服务器上启动一个 Agent，然后通过一个真正的终端从手机上监督并引导它。

像 Claude Code 和 Codex 这样的 Agent 跑在终端里，工作耗时以分钟计，所以有用的问题不是"我能不能跟它聊天"，而是"我能不能从任何地方让它持续运行、让它守规矩"。QuickTUI 是原生 iPhone 和 iPad 应用（另有浏览器客户端），接入你自己托管的服务器上真正的 tmux，所以 Agent 一直活在机器上，而你从手机上驱动它。

启动并监督

  • 发起一次运行。打开一个会话，启动 Agent，交给它一个任务，就是你在办公桌上会敲下的那段提示词。
  • 批准并引导。盯着实时输出，批准工具调用、回答问题，并在 Agent 偏离时重新导向。你看到的是真正的终端，而非摘要。
  • 充当会话保活。走开一会儿，这次运行会在服务器的 tmux 里继续。重新打开应用，会话保活会跨越 Wi-Fi 切 LTE 或 5G、应用切后台和连接中断，重新接回实时画面。

配置你的服务器

在你想运行 Agent 的机器上安装 QuickTUI。它会配置好服务，必要时还能装上 tmux 3.2+。

macOS / Linux

curl -fsSL https://quicktui.ai/q.sh | sh

Windows (PowerShell)

irm https://quicktui.ai/q.ps1 | iex

扫描 quicktui-server --qrcode 完成配对，或者用 URL 和 token 添加服务器。连接默认直连，所以你的代码和密钥绝不经过我们的服务器。

适配任意 Agent

由于 QuickTUI 驱动的是真正的 tmux，它并不绑定单一工具。运行 Claude Code、Codex 或任意 CLI Agent，各自跑在独立的会话里，然后从手机上来回切换。

tmux new-session -s agent
claude   # or: codex, or any CLI agent
同时跑多个 Agent。把每个 Agent 启动在各自的 tmux 会话里，然后从一个应用里统一监督整套：一个在功能分支上、另一个在跑测试、第三个在跟踪日志。单个服务器免费且功能完整；QuickTUI Pro 为一次性买断，可用于无限服务器配置。

常见问题

我能操控哪些 Agent？

任何跑在终端里的 CLI Agent：Claude Code、Codex 或你自己的工具。QuickTUI 驱动的是真正的 tmux，所以它不局限于某个特定产品。

我能批准步骤并引导 Agent，而不只是读取输出吗？

能。你拿到的是实时终端，所以可以从手机上实时回答提示、批准工具调用，并重新导向 Agent。

我离开时 Agent 还会继续运行吗？

会。它跑在你服务器的 tmux 里，在你断开后仍会继续。会话保活会跨越网络切换、应用重启和连接中断，重新接回实时会话。
