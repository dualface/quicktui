如何从 iPhone 运行 Claude Code

Claude Code 跑在终端里，而当会话活在你自己的服务器上时，终端正是 iPhone 能够触及的东西。本指南会在一个 tmux 会话里启动 Claude Code，从 QuickTUI 应用驱动它，在你离开时让它继续运行，还能并排跑好几个会话。

让长时间的终端工作变得可靠，靠的就是同一套办法：把进程留在服务器的 tmux 里，再从任何地方接一个视图上去。QuickTUI 是原生 iPhone 和 iPad 应用（另有浏览器客户端），接入你自己托管的服务器上真正的 tmux，所以无论你的手机是否正看着它，Claude Code 都在持续思考和编辑。

安装服务端

在你想运行 Claude Code 的机器上运行安装器：你的工作站、一台家用服务器，或是一台云主机。它会配置好 QuickTUI 服务，必要时还能装上 tmux 3.2+。

macOS / Linux

curl -fsSL https://quicktui.ai/q.sh | sh

Windows (PowerShell)

irm https://quicktui.ai/q.ps1 | iex

扫描 quicktui-server --qrcode 完成配对，或者用 URL 和 token 手动添加服务器。连接默认直连，所以你的代码和密钥绝不经过我们的服务器。

在会话里启动 Claude Code

在服务器上，打开一个命名的 tmux 会话并在其中启动 Claude Code：

tmux new-session -s claude
claude

在应用里接入 claude 会话，你就来到了实时提示符前。像在终端里一样输入、审阅 diff、批准工具调用，精确地引导 Agent。

让它持续运行，并同时跑多个

  • 让它继续干活。断开或关闭应用，Claude Code 仍在服务器的 tmux 里运行。稍后重新打开，会话保活会重新接回实时画面。
  • 扛得住网络变化。从 Wi-Fi 切到 LTE 再到 5G、切到后台，或是连接中断，都不会打断这次运行。
  • 多个会话。为另一个任务或仓库启动第二个会话（tmux new-session -s review），并在应用里来回切换。
横向对比。Anthropic 提供了内置的远程控制 Claude Code 的方式。QuickTUI 的定位不同：它是一个完整的终端，面向任意 CLI Agent（Claude Code、Codex 或别的什么），跑在你自托管服务器上真正的 tmux 之上，支持多会话，且不要求订阅套餐。哪种适合你的场景就选哪种。

常见问题

关闭应用后 Claude Code 还会继续运行吗？

会。Claude Code 跑在你服务器的 tmux 里，所以在你断开后仍会继续。当你重新打开应用时，QuickTUI 的会话保活会重新接回同一个实时会话。

我能同时跑多个 Claude Code 会话吗？

能。用 tmux new-session -s name 各自启动在独立的 tmux 会话里，然后在 iPhone、iPad 和浏览器上的应用里来回切换。

我的代码会经过 QuickTUI 的服务器吗？

不会。连接默认直连，所以你的代码和密钥只在你的设备与你自己的服务器之间流转。
