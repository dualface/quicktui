如何从手机接入 tmux 会话

要从手机接入 tmux 会话，在运行 tmux 的电脑上安装 QuickTUI 服务端，再在 iPhone、iPad 或 Android（Preview）上打开 QuickTUI App。App 会列出电脑上的 tmux 会话，点开任意一个，就进入你在电脑前离开时的那个实时会话，窗口、窗格和回滚历史都在。

tmux 会在你断开后让电脑上的终端会话继续运行，构建、Agent、日志和 shell 都不会中断。QuickTUI 接入的就是这个 tmux，而不是另开一个 shell，所以无论手机是否连着，会话里的任务都照常运行。

如何开始

  1. 从 App Store 安装 QuickTUI，或安装 Android 应用（Preview），然后打开设置向导。
  2. 选择 通过 SSH 连接并启用增强功能（推荐），填写运行 tmux 的 Mac 或 Linux 电脑的 SSH 登录信息。
  3. 点 安装。App 会通过 SSH 安装 QuickTUI 服务端并自动完成配对。

不支持 SSH 登录的电脑，先在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

QuickTUI 需要 tmux 3.2 及以上版本。安装器会直接使用电脑上已有的 tmux，不会安装或修改它，安装方法见如何安装 tmux。手机与电脑之间的连接端到端加密，默认直连你的电脑。

接入、重连与新建会话

接入正在运行的会话
tmux 会话在会话管理器中显示为工作区。点开任意一个，即可查看它的实时画面，包括窗口、窗格和回滚历史。
断线后接着用
会话一直在电脑上运行。在 Wi-Fi 与蜂窝网络之间切换、App 退到后台或短暂断线后，App 会自动重连，回到你离开的位置。
新建会话
在会话管理器中点 [+] 新建工作区，或在电脑上运行 tmux new -s work，新会话会出现在列表中。
快速执行 tmux 命令
命令面板内置 tmux 命令分组，常用命令点一下即可执行，不必输入组合键。

给会话命名：tmux attach -t claude

在手机上，有名字的会话最容易找到。在名为 claude 的会话中启动 Agent：

tmux new -s claude
claude

在电脑前，用 tmux attach -t claude 打开这个会话；在 App 中，它显示为 claude 工作区，点开就是同一个会话。可以按任务或仓库各开一个会话，例如 tmux new -s review，再在列表中切换。完整步骤见在 iPhone 上运行 Claude Code。

全屏 Agent 与回滚历史

Claude Code、Codex 等 Agent 可能在终端主屏幕上绘制界面，导致 tmux 回滚历史中堆满重复输出。服务端检测到这种情况时，App 会提示如何把 Agent 切换到全屏模式。Claude Code 运行 /tui fullscreen 即可；Codex、Grok Build 与 Pi 的设置方法见 FAQ。

用 tmux 还是 Herdr？

如果你已经习惯 tmux，继续用它就好。如果主要用来运行 AI Agent，可以考虑 Herdr：会话管理器会显示每个 Agent 处于空闲、工作中、等待输入还是已完成。两者可以同时启用；电脑上两者都没有时，安装器会自动安装 Herdr。

常见问题

可以用 iPhone 接入 tmux 会话吗？

可以。在运行 tmux 的电脑上安装 QuickTUI 服务端并完成配对后，tmux 会话会显示为工作区，点开即可接入实时会话。iPad 和 Android（Preview）同样适用。

关闭 App 后 tmux 会话还在运行吗？

在。会话运行在电脑上，而不是手机上。关闭 App、信号中断或切换网络，会话都会继续运行；重新打开 App 即可回到会话。

需要什么版本的 tmux？

tmux 3.2 及以上。安装器会使用电脑上已有的 tmux，不会安装或升级它；电脑上既没有 tmux 也没有 Herdr 时，会改为安装 Herdr。

App 是通过 SSH 连接的吗？

不是。设置向导只在安装服务端时用一次 SSH，之后 App 与 QuickTUI 服务端之间使用端到端加密连接。不支持 SSH 登录的电脑，用一条命令安装服务端，再扫码配对即可。
