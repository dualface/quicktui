在手机上运行 Kimi Code

Kimi Code 运行在电脑的终端里，因此可以在手机上操作它。把 Kimi Code 放在 tmux 或 Herdr 会话中运行，QuickTUI 就能在 iPhone、iPad 或 Android 上打开这个实时会话，全程端到端加密；放下手机后，Kimi Code 照常运行。

Kimi Code 是什么

Kimi Code 是月之暗面（Moonshot AI）推出的终端编程 Agent，开源（MIT 协议），用 kimi 命令启动。它取代了早先基于 Python 的 Kimi CLI（MoonshotAI/kimi-cli），后者已归档停止维护。如果你在找 Kimi CLI，Kimi Code 就是它的继任者。

安装 Kimi Code 与 QuickTUI

  1. 在要运行 Kimi Code 的电脑上安装： 
    # macOS / Linux
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash

# Homebrew
brew install kimi-code

# npm（需要 Node.js 22.19 及以上）
npm install -g @moonshot-ai/kimi-code

# Windows（PowerShell，需要先安装 Git for Windows）
irm https://code.kimi.com/kimi-code/install.ps1 | iex
    然后运行 kimi，用 /login 登录：可以用 Kimi Code 账号（设备码登录），也可以用 Kimi 开放平台的 API Key（KIMI_API_KEY）。中国大陆以外的账号用 kimi login --region global 登录。详见 Kimi Code 文档。
  2. 在手机上安装 QuickTUI：iPhone 和 iPad 从 App Store 下载，Android 使用 Android 应用（Preview）。
  3. 在 App 的设置向导中选择 通过 SSH 连接并启用增强功能（推荐），填写电脑的 SSH 登录信息，然后点 安装。App 会安装 QuickTUI 服务端并自动完成配对；电脑上既没有 tmux 也没有 Herdr 时，会自动安装 Herdr。

不支持 SSH 登录的 Mac 或 Linux 电脑，先在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

Windows 电脑请从 Microsoft Store 获取 QuickTUI Server，从开始菜单打开后扫描它显示的二维码。Windows 上的会话运行在 Herdr 中，Herdr 需另行安装，见安装指南的 Windows 一节。

中国大陆网络可以改用国内安装源，命令见安装指南。连接全程端到端加密，默认直连你的电脑。

从手机启动 Kimi Code

在 App 中打开 Agent 向导，选择 Kimi，QuickTUI 会在当前 tmux 会话中新建窗口，或在当前 Herdr 工作区中新建标签页来启动它。Luvus 后端不支持 Agent 向导。

模式
Default 保留 Kimi Code 的正常审批提示。YOLO 会加上 --yolo，执行操作时不再询问，只建议在允许它随意修改的仓库中使用。
模型
k3-256k、kimi-for-coding-highspeed、k3 或 kimi-for-coding，通过 --model 传入。也可以在「设置 > Agent 模型」中添加自定义模型。
恢复会话
用 --session 继续之前的会话。工作区运行在 Herdr 上时不支持恢复。
工作目录
选择项目文件夹，最近用过的文件夹可以直接点选。常用组合可以保存为预设。

也可以在电脑上自己启动，放在一个有名字的 tmux 会话里，之后在 App 中就能找到：

tmux new-session -s kimi
kimi

在手机上使用 Kimi Code 的建议

发送截图
在输入栏中附加文件、图片或相机照片。文件会上传到电脑（上限 10 MiB），并把路径填入输入内容，Kimi Code 就能读取它。
常用命令一键发送
命令面板内置 Kimi 分组，收录了常用命令，不必在手机键盘上逐字输入。
看清哪个会话需要你
使用 Herdr 时，会话管理器会显示每个 Kimi Code 会话是空闲、工作中、等待输入还是已完成。

Kimi Code 远程控制与 QuickTUI 的区别

Kimi Code 自带远程控制功能：运行 kimi rc（或 kimi web --remote-control）会显示二维码和链接，通过 Kimi 的中转服务在浏览器中打开当前会话。该功能需要 Kimi 付费会员。

QuickTUI 的思路不同：它提供的是电脑上的完整终端，而不是单个会话的浏览器视图。你可以同时运行 Kimi Code、Claude Code、Codex 或其他 CLI Agent，并在同一个 App 中切换。连接端到端加密，默认直连；会话运行在 tmux 或 Herdr 中，App 重启或网络切换后依然保持。两种方式下 Kimi Code 都运行在你自己的电脑上，按自己的使用习惯选择即可。

常见问题

Kimi Code 和 Kimi CLI 是同一个工具吗？

Kimi Code 是 Kimi CLI 的继任者。月之暗面已将基于 Python 的 Kimi CLI 归档，由 Kimi Code 取代，启动命令仍然是 kimi。

关闭 App 后，Kimi Code 还会继续运行吗？

会。它运行在电脑上的 tmux 或 Herdr 会话中，关闭 App 或手机断网都不影响。重新打开 App 即可回到这个实时会话。

在 QuickTUI 中使用 Kimi Code 需要 Kimi 会员吗？

QuickTUI 本身不需要。你只需要满足 Kimi Code 自身的运行条件，即 Kimi Code 账号登录或 Kimi 开放平台 API Key。需要付费会员的是 Kimi 自带的 kimi rc 远程控制功能。

Android 手机可以用吗？

可以。Android 应用目前处于预览阶段，和 iPhone、iPad 版使用同一个 QuickTUI 服务端。
