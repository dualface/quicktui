如何从手机运行 Codex CLI

OpenAI 的 Codex CLI 是一个终端 Agent，所以从手机运行它，归根结底就是接上它所在的终端。本指南会在你自己服务器上的 tmux 会话里启动 Codex CLI，从 QuickTUI 应用驱动它，并在你断开连接后让会话保持存活。

Codex CLI 会在你的文件上实打实地干活，耗时以分钟计而非几秒，所以你希望它待在一台不会走开的机器上。把它留在服务器的 tmux 里，再从手机接一个视图上去。QuickTUI 是原生 iPhone 和 iPad 应用（另有浏览器客户端），接入你自己托管的服务器上真正的 tmux：同一个 Codex 会话，从任何地方都能触及。

安装服务端

在你想运行 Codex CLI 的机器上运行安装器。它会配置好 QuickTUI 服务，如果缺少 tmux 3.2+ 还能替你装上。

macOS / Linux

curl -fsSL https://quicktui.ai/q.sh | sh

Windows (PowerShell)

irm https://quicktui.ai/q.ps1 | iex

扫描 quicktui-server --qrcode 完成配对，或者用 URL 和 token 手动添加服务器。连接默认直连，所以你的代码和密钥绝不经过我们的服务器。单个服务器免费且功能完整；QuickTUI Pro 为一次性买断，可用于无限服务器配置。

在会话里启动 Codex CLI

在服务器上，打开一个命名的 tmux 会话并在其中启动 Codex：

tmux new-session -s codex
codex

在应用里接入 codex 会话，你就来到了实时提示符前。像在本地一样下达指令、读取输出、批准或引导 Agent。

让会话保持存活

  • 它扛得住断连。tmux 让 Codex 在服务器上持续运行；关掉应用，它照样继续。当你回来时，会话保活会重新接回实时画面。
  • 它扛得住网络变化。从 Wi-Fi 切到 LTE 或 5G、把应用切到后台，或是失去信号，都不会停下这次运行。
  • 同时跑多个。用 tmux new-session -s codex2 为另一个任务或仓库启动第二个会话，并在应用里来回切换。
任意 Agent，同一个终端。QuickTUI 驱动的是真正的 tmux，所以它不绑定单一工具：在会话里运行 Codex、Claude Code 或任意 CLI，然后从手机上统一盯着它们。参见从手机操控 AI 编程 Agent。

常见问题

我离开后 Codex CLI 还会继续运行吗？

会。Codex 跑在你服务器的 tmux 里，所以在你断开后仍会继续。当你重新打开应用时，QuickTUI 的会话保活会重新接回同一个实时会话。

我能同时跑 Codex 和 Claude Code 吗？

能。各自启动在独立的 tmux 会话里，然后在应用里来回切换。QuickTUI 是面向任意 CLI Agent 的完整终端，而非单一工具的客户端。

我需要 SSH 吗？

不需要。QuickTUI 通过 HTTP/WebSocket 与它自己的轻量服务端通信。你可以在局域网内、通过 Tailscale 或 Cloudflare Tunnel 这样的 VPN 或隧道，或经由公网地址访问它。
