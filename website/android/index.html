QuickTUI for Android (Preview)

The QuickTUI Android app is in preview. It works with the same QuickTUI server as the iPhone and iPad app, so you can attach to the tmux, Herdr or Luvus sessions on your computer and drive your agents from an Android phone.

Download from GitHub →

The preview is distributed as an APK on GitHub only; it isn't on Google Play. Open the newest release whose name starts with android-preview and download the .apk file under Assets. Each build is removed after about seven days, so always download from the release list rather than saving a direct file link.

About the preview

Free during the preview
Every feature is available, with no limit on the number of computers. In-app purchases and QuickTUI Cloud subscriptions aren't available on Android yet.
Frequent updates
New builds come out often. The app checks for updates on its own and installs them through the Android system installer.
Same server, same features
The terminal, Agent Wizard, Session Manager, file manager, port forwarding, command palette, Input Bar and Shortcuts Bar all work as they do on iPhone. You can also connect to any computer over plain SSH.

Requirements

Phone
Android 8.0 or later
Computer
macOS, Linux or Windows with the QuickTUI server installed. The setup wizard can install it for you over SSH; see the install guide for the other options.

Install

  1. On your phone, open the release list and download the .apk file from the newest android-preview release.
  2. Open the downloaded file. If Android asks, allow your browser or file manager to install unknown apps, then tap Install.
  3. Open QuickTUI and start the setup wizard. Choose Connect Over SSH — Enable Enhanced Features (Recommended) and enter your computer's SSH login. The app installs the server and pairs for you.

On Windows, get QuickTUI Server from Microsoft Store; on a Mac or Linux computer without SSH access, install the server by running a command on the computer. Then pair by scanning a QR code in the app. See Pair a device. Each phone is paired separately, so you can use the Android app alongside an iPhone or iPad.

Updates

When a new build is available, the app shows an update banner. Tap it and the app downloads the new APK, checks its SHA-256 checksum and confirms it's signed with the same certificate as the installed app, then opens the system installer. The first time, Android asks you to allow QuickTUI to install apps.

If update checks keep failing, the app offers to open the GitHub release list so you can download the new build yourself.

Differences from iPhone

Purchases
Not available on Android yet. During the preview, every feature is free.
Account sign-in
Sign in with Google instead of Apple.
Notifications
Agent notifications are delivered through Firebase Cloud Messaging. On Android 13 and later, the app asks for notification permission when you turn notifications on.
Distribution
APK downloads from GitHub, with updates installed from inside the app, instead of the App Store.

Feedback

This is a preview, so you may run into rough edges. Report problems or send suggestions through the support page.
