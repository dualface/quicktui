在手机上运行 ZCode

ZCode 的命令行版运行在电脑的终端里，因此可以通过实时终端在手机上操作它。在 tmux 会话中启动 zcode，QuickTUI 就能在 iPhone、iPad 或 Android 上打开它，全程端到端加密，还能与其他 Agent 放在同一个 App 里管理。

ZCode 是什么

ZCode 是智谱（Z.ai）推出的 AI 编程工作台，也是 GLM 模型的官方 Agent 环境。它以桌面应用为主，支持 macOS、Windows 和 Linux，并以 Apache 2.0 协议开源（zai-org/ZCode）。仓库中还包含命令行版，用 zcode 启动：不带参数进入终端交互界面（TUI），zcode --web 则启动浏览器界面。

如何获得 zcode 命令。ZCode 官方提供的下载是桌面安装包。命令行版需要从开源仓库自行构建：运行 pnpm build:zcode 生成发行包和安装脚本，安装后 zcode 位于 ~/.local/bin，运行时需要 Node.js。具体步骤见仓库 README。登录时可以使用 Z.ai 或智谱开放平台（BigModel）账号，也可以使用 API Key。

安装 QuickTUI

  1. 在手机上安装 QuickTUI：iPhone 和 iPad 从 App Store 下载，Android 使用 Android 应用（Preview）。
  2. 在 App 的设置向导中选择 通过 SSH 连接并启用增强功能（推荐），填写安装了 ZCode 的电脑的 SSH 登录信息，然后点 安装。App 会安装 QuickTUI 服务端并自动完成配对；电脑上既没有 tmux 也没有 Herdr 时，会自动安装 Herdr。

不支持 SSH 登录的 Mac 或 Linux 电脑，先在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

Windows 电脑请从 Microsoft Store 获取 QuickTUI Server，从开始菜单打开后扫描它显示的二维码。Windows 上的会话运行在 Herdr 中，Herdr 需另行安装，见安装指南的 Windows 一节。

中国大陆网络可以改用国内安装源，命令见安装指南。连接全程端到端加密，默认直连你的电脑。

从手机启动 ZCode

在 App 中打开 Agent 向导，选择 ZCode，QuickTUI 会在当前 tmux 会话中新建窗口来启动它。Agent 向导只能在 tmux 后端启动 ZCode；在 Herdr 工作区中，请新建标签页后手动输入 zcode。

模式
Build、Edit、Plan 或 YOLO，通过 --mode 传入。
模型
启动后在 ZCode 内选择。
恢复会话
用 --resume 继续之前的会话。
工作目录
选择项目文件夹，最近用过的文件夹可以直接点选。常用组合可以保存为预设。

也可以在电脑上自己启动，放在一个有名字的 tmux 会话里，之后在 App 中就能找到：

tmux new-session -s zcode
zcode

在手机上使用 ZCode 的建议

发送截图
在输入栏中附加文件、图片或相机照片。文件会上传到电脑（上限 10 MiB），并把路径填入输入内容，ZCode 就能读取它。
与其他 Agent 并行
为每个 Agent 开一个独立的 tmux 窗口或会话，比如一个跑 ZCode，另一个跑 Claude Code 或 Kimi Code，在 App 中随时切换。
没有实时状态
Herdr 不识别 ZCode，会话管理器不会显示它的空闲、工作中等状态，需要时打开会话查看。

ZCode 远程控制与 QuickTUI 的区别

ZCode 桌面应用自带远程控制：它会显示二维码和链接（也可以通过 Bot Channel 连接），手机连接后可以控制整个桌面窗口，浏览其中的工作区和任务，并继续向 Agent 发送指令。命令仍由各工作区所连接的机器执行。

QuickTUI 面向的是另一种用法：它连接的是电脑上的终端，因此配合的是 ZCode 命令行版而不是桌面应用，还可以在同一处运行其他 CLI Agent。连接端到端加密，默认直连；会话运行在 tmux 中，不需要一直开着桌面应用。如果你主要在 ZCode 桌面应用里工作，用它自带的远程控制更顺手；如果你习惯在终端里运行 Agent，QuickTUI 更合适。

常见问题

可以用 QuickTUI 控制 ZCode 桌面应用吗？

不可以。QuickTUI 连接的是终端会话，配合的是 ZCode 的 zcode 命令行版。控制桌面应用请使用 ZCode 自带的远程控制。

zcode 命令有官方安装包吗？

ZCode 官方发布的是桌面安装包。命令行版需要从开源仓库构建，构建过程会生成它自己的安装脚本，步骤见 ZCode README。

为什么 Agent 向导不能在 Herdr 中启动 ZCode？

Herdr 只能启动它识别的 Agent，其中不包括 ZCode。请在 tmux 后端使用 Agent 向导，或在 Herdr 标签页中手动输入 zcode。

关闭 App 后，ZCode 还会继续运行吗？

会。它运行在电脑上的 tmux 会话中，关闭 App 不影响。重新打开 App 即可回到这个实时会话。
