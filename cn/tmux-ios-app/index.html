iOS 上的 tmux：从 iPhone 和 iPad 接入你的 tmux 会话

iOS 上没有官方的 tmux 应用，你也不需要。你真正想要的，是从手机或平板接上自己机器里已经在运行的 tmux 会话，从上次离开的地方精确续上。这正是 QuickTUI 所做的事。

tmux 让你的终端会话在服务器上持续运行：长时间的构建、编程 Agent、日志跟踪和 SSH shell，在你断开连接后都能继续存活。一直缺的那块拼图，是从 iPhone 或 iPad 顺畅接入它们的方式。QuickTUI 是原生 iOS 客户端（另有 iPad 与浏览器版本），通过你自己的服务器接入这些会话，中间没有任何第三方。

一个"iOS tmux 客户端"应该做到什么

  • 接入，而非重跑。两次接入之间，你的会话一直活在服务器上；打开应用就直接回到实时画面，输出完好无损。
  • 真正的终端，而非聊天框。tmux 的窗口、窗格、回滚缓冲和复制模式：iPhone、iPad 与浏览器上看到的是同一个画面。
  • 扛得住网络变化。从 Wi-Fi 切到 LTE 再到 5G、把应用切到后台，或是连接中断，都不该让你丢失位置。
  • 始终属于你。默认自托管、默认直连，你的代码和密钥绝不经过别人的云。

动手配置（约两分钟）

在运行 tmux 会话的机器上安装 QuickTUI 服务端。它会配置好服务，必要时还能替你装上 tmux 3.2+。

macOS / Linux

curl -fsSL https://quicktui.ai/q.sh | sh

Windows (PowerShell)

irm https://quicktui.ai/q.ps1 | iex

然后扫描 quicktui-server --qrcode 完成扫码配对，或者用 URL 和 token 手动添加服务器。打开一个会话，你就接上了。想要逐步操作的版本，参见从手机接入 tmux 会话。

它真的是 tmux 吗？

是的。QuickTUI 驱动的是你服务器上真正的 tmux，而不是重新实现的替代品。你现有的 ~/.tmux.conf、按键绑定、窗口和窗格全都生效。如果尚未安装 tmux，安装器可以配置一份受支持的构建；你也可以用 QUICKTUI_TMUX_BIN 指向已有的二进制文件。

在 tmux 里跑编程 Agent？QuickTUI 正是为此而生：在会话里启动 Claude Code、Codex 或任意 CLI Agent，然后从手机上盯着它。参见从 iPhone 运行 Claude Code。

常见问题

iOS 上有官方的 tmux 应用吗？

没有。tmux 是一个服务器端程序，没有官方 iOS 应用。QuickTUI 是原生 iOS 客户端，接入运行在你自己服务器上的 tmux。

我需要 SSH 吗？

不需要。QuickTUI 通过 HTTP/WebSocket 与它自己的轻量服务端通信。你可以在局域网内、通过 VPN 或隧道（Tailscale、Cloudflare Tunnel），或经由公网地址访问它。

它能在 iPad 上用吗？

能。同一个应用、同一个实时会话，在 iPhone 和 iPad 上都能运行，任何浏览器里也一样。
