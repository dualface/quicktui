如何从手机接入 tmux 会话

tmux 让你的终端会话在断开连接后仍在服务器上运行：长时间的构建、编程 Agent、日志跟踪和 shell 都能保持存活。本指南带你走一遍用 QuickTUI 从 iPhone 或 iPad 接入这些会话、在掉线后重新接回，以及在需要时新建会话的完整流程。

tmux 持久化背后的想法很简单：会话活在机器上，而不在客户端。你把一个视图接上去，再断开，工作照常进行。QuickTUI 是原生应用（另有浏览器客户端），接入你自己服务器上真正的 tmux，所以你在手机上打开的会话，就是你在办公桌终端里离开的那一个。

安装服务端

在运行 tmux 会话的机器上运行安装器。它会配置好 QuickTUI 服务，如果缺少 tmux 3.2+ 还能替你装上。

macOS / Linux

curl -fsSL https://quicktui.ai/q.sh | sh

Windows (PowerShell)

irm https://quicktui.ai/q.ps1 | iex

连接默认直连，所以你的代码和密钥绝不经过我们的服务器。单个服务器免费且功能完整；QuickTUI Pro 为一次性买断，解锁无限服务器配置。

配对应用

在服务器上生成配对码，扫一次即可：

quicktui-server --qrcode

在 iPhone 或 iPad 上打开 QuickTUI 应用，扫描二维码，服务器就添加好了。如果你更喜欢手动输入信息，也可以用 URL 和 token 添加。

打开、接入与重新接回

  • 接入正在运行的会话。QuickTUI 会列出服务器上的 tmux 会话；点一个，你就直接进入实时画面，回滚缓冲完好无损。
  • 掉线后重新接回。从 Wi-Fi 切到 LTE 或 5G、把应用切到后台，或是失去信号，都不会结束会话。会话保活为你守住位置，重新打开应用就回到原处。
  • 新建会话。在服务器上运行 tmux new-session -s work，或在应用里打开一个 shell 从那儿启动；命名后的会话随即出现在列表里，可从任意设备接入。
要和编程 Agent 打交道？在 tmux 会话里启动 Claude Code、Codex 或任意 CLI 工具，然后从手机上盯着它。参见从 iPhone 运行 Claude Code。

常见问题

如果我的手机掉线，会话还在吗？

在。tmux 让会话在服务器上持续运行，QuickTUI 的会话保活会在网络切换、连接中断或应用重启后重新接回，所以你能从离开的地方续上。

我要怎么新建一个 tmux 会话？

在服务器上运行 tmux new-session -s name，或在应用里打开一个 shell 从那儿启动。命名后的会话会出现在 QuickTUI 的列表里，可从 iPhone、iPad 或浏览器接入。

我需要 SSH 吗？

不需要。QuickTUI 通过 HTTP/WebSocket 与它自己的轻量服务端通信。你可以在局域网内、通过 Tailscale 或 Cloudflare Tunnel 这样的 VPN 或隧道，或经由公网地址访问它。
