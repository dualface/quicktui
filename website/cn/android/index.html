Android · Preview

QuickTUI Android 应用（Preview）

QuickTUI Android 版目前处于预览阶段。它和 iPhone、iPad 版使用同一个 QuickTUI 服务端，让你在 Android 手机上接入电脑里的 tmux、Herdr 或 Luvus 会话，随时操作 Agent。

从 GitHub 下载 →

预览版只以 APK 形式在 GitHub 发布，没有上架 Google Play。打开名称以 android-preview 开头的最新发布，在 Assets 中下载 .apk 文件。每个构建约 7 天后删除，请始终从发布列表下载，不要保存文件的直接链接。目前没有国内镜像，在中国大陆访问 GitHub 可能较慢或下载失败。

关于预览版

预览期间免费
全部功能可用，不限电脑数量。Android 版暂不支持应用内购买和 QuickTUI Cloud 订阅。
更新频繁
新构建发布较频繁。App 会自动检查更新，并通过 Android 系统安装器完成安装。
同一服务端，同样的功能
终端、Agent 向导、会话管理器、文件管理器、端口转发、命令面板、输入栏与快捷栏都和 iPhone 版一致，也可以直接通过 SSH 连接任意电脑。

系统要求

手机
Android 8.0 及以上
电脑
装有 QuickTUI 服务端的 macOS、Linux 或 Windows 电脑。设置向导可以通过 SSH 自动安装服务端，其他安装方式见安装指南。

安装

  1. 在手机上打开发布列表，从最新的 android-preview 发布中下载 .apk 文件。
  2. 打开下载的文件。如果系统提示，允许浏览器或文件管理器安装未知应用，然后点 安装。
  3. 打开 QuickTUI，进入设置向导。选择 通过 SSH 连接并启用增强功能（推荐），填写电脑的 SSH 登录信息。App 会自动安装服务端并完成配对。

Windows 电脑从 Microsoft Store 获取 QuickTUI Server；不支持 SSH 登录的 Mac 或 Linux 电脑，先在电脑上运行安装命令。之后在 App 中扫码配对，见配对设备。每台手机分别配对，Android 版可以和 iPhone、iPad 同时使用。

更新

有新构建时，App 会显示更新提示。点击后，App 下载新的 APK，校验 SHA-256 并确认签名证书与已安装的 App 一致，然后打开系统安装器。第一次更新时，Android 会要求你允许 QuickTUI 安装应用。

如果多次检查更新失败，App 会提供打开 GitHub 发布列表的入口，你可以手动下载新构建。

与 iPhone 版的区别

购买
Android 版暂不支持购买。预览期间，全部功能免费。
账号登录
使用 Google 账号登录，而不是 Apple 账号。
通知
Agent 通知通过 Firebase Cloud Messaging 推送。Android 13 及以上版本，会在你开启通知时请求通知权限。
分发方式
从 GitHub 下载 APK，在 App 内安装更新，不经过 App Store。

反馈

预览版可能还有不完善的地方。遇到问题或有建议，请通过支持页面联系我们。
