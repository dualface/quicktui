QuickTUI 对比 Termius

Termius 是一款广受欢迎的通用 SSH 客户端；QuickTUI 是一款专为 tmux 加编码智能体打造的 客户端。它们的重叠之处在于都把终端放到了你的手机上，但它们是为不同的任务而生的。

Termius 是一种精致的、跨平台的方式，用于 SSH 连入许多主机、管理密钥并保持一份整洁的连接列表。 QuickTUI 更窄也更深：它接入你自己服务器上的真实 tmux，运行 Claude Code、Codex 或任何 CLI 智能体，并 开箱即用地跨断线保持会话存活。

通用 SSH vs tmux 与智能体

Termius 是一款通用 SSH 客户端，并不专门针对 tmux 或智能体。你当然可以在一个 Termius SSH 会话里运行 tmux 和编码智能体，但那套配置和管理都得你自己来。QuickTUI 把 tmux 和智能体监督内建进产品，因此窗口、 窗格、回滚缓冲和重新接入是默认体验，而不是你需要自行拼装的东西。

会话持久性

用一个纯 SSH 客户端时，除非你已经自己配好了 tmux 或 screen，否则连接掉线可能会丢掉你的会话。QuickTUI 的会话保持是内建的：切换网络、把应用切到后台或失去信号，你都能从离开的地方精确地重新接入。

你该选哪个？

如果你要管理一批服务器，想要一款一流的通用 SSH 客户端，具备密钥管理和广泛的协议特性，那么 Termius 更契合；那正是它的设计目标，QuickTUI 也不试图取代它。如果你的目标明确是在手机上、在真实 tmux 里运行并 监督编码智能体，自托管且直连、会话持续存活，那么 QuickTUI 是更专注的工具。许多人两者并用，各得其所。

常见问题

QuickTUI 是像 Termius 那样的 SSH 客户端吗？

不是。QuickTUI 与它自己的轻量服务器通信并驱动真实 tmux，而不是一款通用 SSH 客户端。你仍然可以通过 局域网、VPN 或隧道连到那台机器。

我可以在使用 QuickTUI 的同时继续用 Termius 吗？

可以。它们服务于不同的需求：Termius 用于广泛的 SSH 访问，QuickTUI 用于 tmux 和编码智能体，两者并用 并无冲突。
