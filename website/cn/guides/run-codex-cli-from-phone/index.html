在手机上运行 Codex CLI

要在手机上使用 OpenAI 的 Codex CLI，做法是让它在你自己的电脑上运行，再用 QuickTUI App 操作它的终端。你离开电脑时它照常工作，你可以在 iPhone、iPad 或 Android 上查看进度、处理审批、交代下一步任务。

Codex CLI 是什么

Codex CLI 是 OpenAI 推出的终端编程 Agent，能在代码仓库中修改文件、执行命令，并通过审批与沙箱设置控制它能自主做多少事。QuickTUI 把这个终端带到手机上，并接入 tmux 或 Herdr 会话，断开连接后 Codex 仍会继续运行。

安装 Codex CLI 与 QuickTUI

  1. 在要运行 Codex 的电脑上安装它，然后运行一次 codex，选择 Sign in with ChatGPT 登录。 
    # macOS / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

# 也可以用 npm / Homebrew
npm install -g @openai/codex
brew install --cask codex
  2. 在手机上安装 QuickTUI：iPhone 和 iPad 从 App Store 下载，Android 使用 Android 应用（Preview）。
  3. 在 App 的设置向导中选择 通过 SSH 连接并启用增强功能（推荐），填写电脑的 SSH 登录信息，点 安装。App 会安装 QuickTUI 服务端并自动完成配对；电脑上没有 tmux 和 Herdr 时，会自动安装 Herdr。

不支持 SSH 登录的 Mac 或 Linux 电脑，先在电脑上运行安装命令，再扫码配对：

curl -fsSL https://quicktui.ai/q.sh | sh

Windows 电脑请从 Microsoft Store 获取 QuickTUI Server，从开始菜单打开后扫描它显示的二维码。Windows 上的会话运行在 Herdr 中，Herdr 需另行安装，见安装指南的 Windows 一节。

在 Windows 上，QuickTUI 的会话运行在 Herdr 中，所以 Windows 电脑上的 Codex 用法相同。手机与电脑之间的连接全程端到端加密，默认直连。详见安装指南。

从手机启动 Codex

在 App 中打开 Agent 向导，选择 Codex，QuickTUI 会在当前 tmux 会话中新建窗口，或在当前 Herdr 工作区中新建标签页来启动它。Luvus 后端不支持 Agent 向导。

模式
Default 保留 Codex 自己的审批与沙箱设置。YOLO 会加上 --dangerously-bypass-approvals-and-sandbox，不经审批、不使用沙箱，只在确认安全的环境中使用。
模型
gpt-6-astra、gpt-5.6-sol、gpt-6-sol 或 gpt-6-luna，通过 --model 传入。也可以在「设置 > Agent 模型」中添加自定义模型。
推理强度
通过 -c model_reasoning_effort=… 传入。
恢复会话
用 codex resume <id> 继续之前的会话。工作区运行在 Herdr 上时不支持恢复。
工作目录
选择项目文件夹，最近用过的文件夹可以直接点选。常用组合可以保存为预设。

也可以在电脑上自己启动，放在一个有名字的 tmux 会话里：

tmux new-session -s codex
codex

在手机上使用 Codex 的建议

tmux 中的回滚历史
Codex 在 tmux 主屏幕中绘制时，输出可能在回滚历史中重复出现。App 检测到这种情况会显示提示。在 ~/.codex/config.toml 的 [tui] 下设置 alternate_screen = "always" 即可，详见 FAQ。
发送截图
在输入栏中附加文件、图片或相机照片。文件会上传到电脑（上限 10 MiB），并把路径填入输入内容，Codex 就能读取它。
常用命令一键发送
命令面板内置 Codex 分组，收录了常用命令，不必在手机键盘上逐字输入。
看清哪个会话需要你
使用 Herdr 时，会话管理器会用图标标出每个 Codex 会话，并显示它是空闲、工作中、等待输入还是已完成。

常见问题

手机上能用 Codex CLI 吗？

Codex CLI 运行在电脑上，而不是手机本身。借助 QuickTUI，你可以在手机上通过真实终端操作电脑里的 Codex，包括处理审批和继续追问。

Android 手机可以吗？

可以。QuickTUI Android 应用目前处于预览阶段，和 iPhone、iPad 版连接同一个 QuickTUI 服务端。

关闭 App 后，Codex 还会继续运行吗？

会。它运行在电脑上的 tmux 或 Herdr 会话中，关闭 App 后照常运行。重新打开 App，会回到正在进行的会话。

Codex 装在 Windows 电脑上，也能用手机操作吗？

可以。从 Microsoft Store 获取 QuickTUI Server，再安装 Herdr，然后扫码配对即可。Windows 上的会话运行在 Herdr 中。

可以同时运行 Codex 和 Claude Code 吗？

可以。每个 Agent 放在各自的 tmux 窗口或 Herdr 标签页中，在 App 里随时切换。参见在 iPhone 上运行 Claude Code。
